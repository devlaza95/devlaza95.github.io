Jarvis privacy policy

Last updated 29 October 2026. Back to the Jarvis home page.

Who this covers

Jarvis is a personal assistant used by one person, its author, with the author's own Google account. It is not offered to anyone else. Mail in the author's inbox is written by other people; Jarvis handles it only as described below.

What Jarvis accesses

Read-only access to the author's Gmail (gmail.readonly) and Google Calendar (calendar.readonly), granted by the author on Google's consent screen. Jarvis cannot send, delete or change mail or calendar events.

How it is used

To write a short summary, a category and a priority for each new message, to alert the author when a message needs attention, and to answer the author's own questions about their mail and calendar. It is not used for advertising, profiling or any other purpose.

Where the data goes

  • Anthropic's API. The text of a new message (up to roughly 6,000 tokens, with attachment names but not attachment contents) and the calendar events the author asks about are sent to Anthropic's API, which runs the Claude model that writes the summary or the answer.
  • Telegram. Summaries and answers are sent to the author in a private chat with the author's own Telegram bot.
  • The author's computer. Jarvis stores a summary row for each message (sender, subject, category, priority, short summary, requested actions, deadlines) in a database on the author's own computer. It does not store message bodies. The Google sign-in token is kept in a file on that computer that only the author's user account can read.

Nothing is sold. Nobody other than the author reads the data. Jarvis does not use it to train AI models.

Limited use

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

Summaries stay on the author's computer until the author deletes them. The author can withdraw Jarvis's access to Google at any time at myaccount.google.com/permissions, after which Jarvis can read nothing from Gmail or Calendar, and can delete the stored summaries and the token file.

Changes

If what Jarvis does with Google data changes, this page is updated first and the date above changes.
